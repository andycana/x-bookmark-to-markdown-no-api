X Bookmark → Markdown (No API)

Save bookmarked posts from X/Twitter to local Markdown instantly — no API key, no model call, no token cost.

View on GitHub Install Guide

Why this extension

Zero API dependency

Everything runs locally in your browser extension context.

Bookmark = save

Click bookmark once, Markdown is saved immediately to your Downloads folder.

Original content only

No AI summary, no rewriting — clean source text for your own analysis pipeline.

Privacy-friendly

No third-party content upload for generation requests.

Quick install

  1. Open chrome://extensions/.
  2. Turn on Developer mode.
  3. Click Load unpacked.
  4. Select the extension folder.

Default output: Downloads/x-bookmark-local/
